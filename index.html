Enterprise Retail ERP Analytics Platform

PostgreSQL · SQL Server · Python · Tableau
LIVE ON GITHUB →

An end-to-end retail ERP analytics platform: 25+ normalized entities across 9 business domains, a weighted Python transaction generator simulating 13 months of realistic retail operations, and three Tableau executive dashboards on top.

  • 30K+ orders generated across 3 stores and 208 customers — with Pareto-distributed customer spend, realistic payment-method mix, and weekday + holiday seasonality.
  • Generator performance optimized with single-pass reference loading (~150K redundant queries eliminated) and seeded, reproducible runs.
  • Every dataset validated with SQL integrity and distribution checks — orphan detection, revenue-split verification against design targets — before Tableau extracts refresh.
  • Complete Order-to-Cash and Procure-to-Pay lifecycle modeling: PO management, supplier invoicing, BOM consumption, and payment reconciliation.

Retail Analytics Engineering Pipeline

Python · PostgreSQL · dbt · Tableau
ANALYTICS ENGINEERING

An end-to-end analytics engineering pipeline built from scratch — raw data generation in Python, a normalized PostgreSQL database, a modular dbt transformation layer, and Tableau dashboards on top.

  • Generated realistic retail transactional data (orders, customers, products, payments) using Python and loaded it into a normalized PostgreSQL database with multiple related tables.
  • Built a modular dbt pipeline with staging, dimension, and fact models following star schema principles — transforming raw tables into business-ready analytical datasets.
  • Implemented dbt data quality tests (not_null, relationships) to validate data integrity and enforce referential consistency before any data reaches the reporting layer.
  • Developed reusable mart-layer models and built interactive Tableau dashboards analyzing sales performance, revenue trends, customer behavior, product performance, and store KPIs.
